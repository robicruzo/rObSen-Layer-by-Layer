# rObSen, Layer by Layer

A companion book for Alan Labouseur's Operating Systems course (CMPT 424, Marist): the course's concepts, chapter by chapter, told through rObSen, a browser-based operating system written in TypeScript for the semester project.

**Read it:** https://robicruzo.github.io/robsen-layer-by-layer/

Built with [mdBook](https://rust-lang.github.io/mdBook/). The rendered site lives on the `gh-pages` branch. The full rObSen source is not published here (the course requires the project repository to stay private); the book quotes only excerpts.
